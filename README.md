# React useEffect Practice Project

A beginner-friendly React project created to practice and understand different concepts of React's `useEffect` hook along with state management, refs, browser APIs, event listeners, timers, session storage, and React Router.

## 🚀 Project Overview

This project contains **10 practical examples of `useEffect`**.

Each example demonstrates a different use case and can be accessed through its own route.

The project also includes:

- A professional Home page
- Navigation using `react-router-dom`
- 10 separate `useEffect` examples
- A custom 404 Not Found page
- Responsive UI using Tailwind CSS
- Browser APIs such as `sessionStorage`
- Event listeners
- `setInterval`
- `useRef`
- Dynamic state updates
- Automatic file downloading
